# Smart Circuit Simulator — UI/UX Redesign Completion Plan

## Context

The repo already contains an uncommitted, partially-completed redesign of this exact spec: design tokens (`src/styles/tokens.css`), dark/light/system theme with anti-FOUC boot script, en/fa i18n infra, breakpoint plumbing (`useBreakpoint`, overlay/sheet state machine), and several **fully written but orphaned** new components. The simulation engine, stores, canvas, and existing workflows are solid and must not be rewritten — spec critical rules honored.

**What's orphaned/broken today:**
- `MeasurementsPanel.tsx` + `SimConsole.tsx` — written, but `BottomPanel.tsx` still renders a hardcoded placeholder and no console tab
- `CanvasContextMenu.tsx` — never mounted (canvas `onContextMenu` only preventDefaults)
- `SettingsDialog.tsx` — rendered but unreachable (nothing calls `setDialog('settings')`)
- `MobileDock.tsx` / `ColorLegend.tsx` / `Onboarding.tsx` — mounted but have **zero CSS** and **zero i18n keys** (render raw keys like `legend.current`; dock invisible since `--dock-h: 0px`)
- `data-bp` / `data-overlay` / `data-scope-full` root attributes set by `App.tsx` but consumed by no CSS
- `.sheet-backdrop`, `.btn`, `.chip`, `.bottom-panel-resize(-grip)`, `.ctx-menu`, `.measure-grid`, `.sim-console` classes referenced but undefined in `global.css`
- No pinch-zoom/two-finger pan; spec-required items missing: oscilloscope CSV export, unit-aware inputs, favorites/recents UI, BJT inspector section, component mirroring, unified speed controls, Ctrl+N/S/O

## Phase 0 — Baseline safety commit
Commit the current working tree as-is (`git add -A && git commit`) so the in-flight work is a restorable checkpoint before further edits.

## Phase 1 — Activate the orphaned UI (wiring + i18n + CSS)
1. **i18n** (`src/i18n.ts`): add missing key families to **both** en + fa dictionaries: `legend.*`, `mobile.*`, `onboard.*`, `settings.*`, `theme.dark/light/system`, `empty.measurements*`, `empty.console/Ok`, `sim.failed`, `tab.console`, plus new keys used below.
2. **CSS** (`src/styles/global.css`, tokens where needed): styles for `.mobile-dock`/`.dock-btn`, `.sheet-backdrop`, `.color-legend`, `.ctx-menu`, `.onboard-*`, `.viz-fields`, `.measure-grid`/`.measure-card`, `.sim-console`/`.console-tag`, `.bottom-panel-resize(-grip)`, `.chip`, `.error-state`, and `.btn`/`.btn.primary` base. All using existing tokens, logical properties (RTL-safe), 44px touch targets (`--touch`), `prefers-reduced-motion` respected.
3. **Wire `BottomPanel.tsx`**: render `MeasurementsPanel` for the measurements tab; add a **Console** tab rendering `SimConsole` (the `'console'` tab id already exists in the type).
4. **Mount `CanvasContextMenu`** inside `.canvas-wrap` in `CircuitCanvas.tsx` (its window-level listener already scopes to `.canvas-wrap`).
5. **MenuBar**: add a Settings gear in the header utility cluster + File-menu entry → `setDialog('settings')`; add View-menu entry for the color legend (`setLegendVisible`).
6. **Scope fullscreen**: add a toggle button to the Oscilloscope toolbar → `setScopeFullscreen`, plus CSS keyed off `[data-scope-full='true']` on the root.

## Phase 2 — Tablet + mobile layout (responsive completion)
1. **MobileDock**: visible only on `[data-bp='tablet'|'mobile']`; set `--dock-h` (≈56px + safe-area) via `data-bp` selectors in `tokens.css`/`global.css`; compact MenuBar and collapsed side panels on mobile (library/inspector become full-height overlay sheets — the overlay state machine already exists); StatusBar slimmed on mobile.
2. **Touch gestures in `CircuitCanvas.tsx`**: Pointer-Events based pinch-to-zoom + two-finger pan (zoom-to-midpoint, clamp to existing MIN/MAX_ZOOM), preserving the existing single-pointer pan/move/draw state machine. Keep `touch-action: none` scoped to the canvas surface only.
3. Tablet: drawers via `data-bp` CSS; desktop columns untouched at ≥1024px.

## Phase 3 — Spec-required feature completion (no engine changes)
1. **Unified sim speed**: one preset list (0.1–10) + consistent slider clamp shared by `MenuBar` popover and `SimulationControls`.
2. **Keyboard**: implement advertised Ctrl+N/S/O in `useKeyboard.ts` (New uses the shared dialog shell instead of `window.confirm`).
3. **Oscilloscope CSV export**: Export button serializing `channelSamples` buffers (t + per-channel V/I columns) to a downloaded `.csv`.
4. **Library**: favorites star + recents strip in `LibrarySidebar` (uiStore `favoriteTypes`/`recentTypes` already persist); reorganize categories to Sources / Passive / Semiconductors / Switches / Actuators in `src/core/symbols.tsx` (existing components only — **no new component types**, since spec forbids engine work).
5. **Inspector**: BJT section (NPN/PNP, datasheet presets from `src/core/bjtModel.ts`, β, advanced thermal collapsed); `UnitInput` with engineering-prefix parsing ("10k", "100u" — parser reuses the SI prefix table in `core/labels.ts` `formatValue`) applied to value fields; inline validation messages.
6. **Mirror/flip**: `mirrored?: boolean` on `CircuitComponent`, honored in `core/geometry.ts` `terminalWorld` + symbol render transform; toggle via context menu + inspector button + Shift+R. Add a unit test for mirrored terminal positions (protects wire connectivity).
7. **Toasts**: small `Toast` component (aria-live, auto-dismiss) driven off the existing `uiStore.statusKey` transient-status mechanism, used for solver failure / save / copy events.
8. **Design-system cleanup**: extract shared `DialogShell` (dedupe About/Transfer/Settings); tokenize remaining chrome hardcoded colors (Inspector hexes, light-theme tab overrides, `#04121c` → `--on-accent` token); fix dead Tailwind classes in `ZenerAnalyzer.tsx`; move remaining hardcoded English strings (scope LIVE/HELD, stale-probe, AnalyzerPanel headers) into i18n.
9. **Undo coalescing**: Inspector text edits commit one history entry per edit session (blur/debounce) instead of per keystroke, via existing `circuitStore.commit`.

## Phase 4 — Verification & deliverables
- `npm run typecheck`, `npm test`, `npm run build` — all must pass; add unit tests where touched (units parser, mirrored geometry).
- Browser-test real interactions at 1920×1080, 1440×900, 1366×768, 1024×768, 768×1024, 390×844, 375×667, 360×800 (dev server + browser automation): place/wire/edit/run/scope on mobile, drawers on tablet, no horizontal overflow; verify dark + light + Persian RTL passes; capture screenshots of major layouts.
- Update README (design system, themes, responsive behavior, shortcuts) + list of modified files.

## Constraints honored throughout
Simulation engine (`src/core/solver.ts` and friends) untouched; component placement/wire connectivity/serialization preserved (mirror is opt-in per component); keyboard shortcuts and RTL preserved; canvas remains the visual focus; animations synced to sim state only.
